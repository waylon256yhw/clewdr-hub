## 它能做什么

<CardGrid>
	<Card title="零依赖部署" icon="rocket">
		单个静态链接二进制，前端编译嵌入，SQLite WAL 自动建库。一条命令装好并注册开机自启。
	</Card>
	<Card title="透明代理" icon="random">
		直接转发 `/v1/messages`，不注入系统提示词；仅为兼容 Anthropic 模型行为做最小参数归一化。
	</Card>
	<Card title="多账号调度" icon="seti:db">
		Cookie / OAuth / API Key 账号池 + round-robin + 亲和性缓存 + per-account 并发槽，支持「优先消耗」。
	</Card>
	<Card title="团队隔离" icon="seti:lock">
		用户 → 策略 → API Key，并发 / RPM / 周预算 / 月预算多重限额，超限直接拒绝。
	</Card>
	<Card title="OpenAI 兼容入口" icon="seti:json">
		`POST /v1/chat/completions` + `/v1/models` 格式协商，零改造对接 OpenAI SDK 客户端。
	</Card>
	<Card title="内嵌管理后台" icon="laptop">
		总览 / 运维 / 账号池 / 代理 / 用户 / Key / 日志 / 设置，SSE 实时推送。
	</Card>
</CardGrid>
