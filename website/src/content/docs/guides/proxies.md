代理是独立资源，在后台 **代理** 页维护。一个实例可同时保存多条代理。

## 多个备用代理

- 代理可同时保存多条，**不做自动轮换**；按需为账号绑定。
- 每个[账号](../account-pool/)可单独选择一个代理，也可以留空直连。
- 适合不同账号走不同出口。

## 简易测试

后台代理页的测试在**服务器侧**执行，用于确认基础连通性，会展示延迟、出口 IP 和地区信息。

:::note
这是通用代理连通性测试，**不代表**一定适用于某个具体上游服务。它请求一个公共 IP 回显服务来判断出口，不会真正打到 Anthropic。
:::

## 生效范围

账号绑定代理后，该账号的这些出站路径都会走代理：Claude Messages 请求、OAuth 交换 / 刷新、OAuth probe / account test。代理资源模型与测试实现细节见[开发 · 代理与测试](../../dev/proxy/)。
